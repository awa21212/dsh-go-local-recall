# 语料检索（local-decay-rag）

> dsh-go 手机插件：本地语料检索，块级时间戳 + 时间衰减。410 行纯 JS，零依赖、不用嵌入模型、不联网。

把 [decay-rag](https://github.com/) 那套「按块时间戳 + 时间衰减」的检索搬进 dsh-go 手机 App 的原生界面。
纯 JS，不需要 python、numpy、嵌入模型或 GPU。

## 用

1. 在输入框写下问题，先不要发送；
2. 点输入框上方的 **「查语料」**；
3. 弹出面板：最多 6 条命中，每条显示 `文件 · 第几块 / 日期 / 综合分`；
4. 点任意一条复制该片段，或点「复制第一条」；
5. 语料有更新时，点「重建索引」重读，不用重启引擎。

## 模型工具 `recall_corpus`

插件同时给模型注册了一个工具。你问「我以前写过什么」「当时怎么定的」「翻一下我的笔记」时，
模型会自己调用它检索本机语料，不用你先点胶囊。返回格式是「文件名 · 第几块 · 日期 · 综合分 + 正文片段」。

排序和面板一致：相似度乘以时间衰减，越新越靠前。

## 配置

插件目录下的 `config.json`（可选，参考 `config.example.json`）：

| 字段 | 默认 | 说明 |
|---|---|---|
| `corpus` | `/sdcard/notes` | 语料根目录，递归读 `.md` / `.txt` |
| `halfLife` | `30` | 衰减半衰期（天） |
| `topK` | `6` | 返回条数，上限 20 |
| `skip` | `[]` | 额外不进索引的目录名 |
| `mode` | `gate` | `gate` 乘性门 / `additive` 加性 0.75+0.25 |
| `gate` | `0.85` | 乘性门的下限，衰减为 0 时保留的比例 |
| `refreshMs` | `20000` | 多久检查一次语料有没有变；`0` 关闭自动重建 |

改完 `lib/` 或 `config.json` 后，在 App 的「引擎」页重启引擎才生效。

**语料更新不用管**：插件每 20 秒比对一次目录指纹（文件数 / 总字节 / 最新 mtime），
一旦变了就在后台重建整个索引。你在电脑上改完、把导出的目录覆盖到手机上，
下一次搜就是新的，不需要点「重建索引」。300 块的语料重建约 0.4 秒。

## 算法

```
相似度 = 0.72 × 字符二元/三元组余弦 + 0.28 × 查询二元组命中率
衰减   = 0.5 ^ (块龄 / 半衰期)
综合   = 相似度 × (0.85 + 0.15 × 衰减)      # 乘性门，默认
```

早先的 `0.75 × 相似度 + 0.25 × 衰减`（加性）仍可用 `config.json` 的 `"mode": "additive"` 打开。
在 365 天单文件日记的中文语料基准里，加性版首中 58%、乘性门 83%：加性权重会让「新但无关」的块把正确答案挤出前三。换英文语料复核时，乘性门只在前三领先、首中持平——所以这是语料相关的经验值，不是定律。

块龄来自**块自己的日期**，不是文件修改时间：

1. 文件名里的日期（`决策记录_2026-11-06.md`）；
2. 块内**离文件 mtime 最近**的日期（不是第一个——报告开头常写回测起点那种历史日期）；
3. `10-31` 简写（年份按当前年推，未来超过 30 天则退一年）；
4. 兜底用文件 mtime。

## 证据：为什么非做块级时间戳不可

如果块的时间戳取文件 `mtime`，最典型的一类个人语料——**一个文件写到底**（日记、日志、
周报）——所有块共享同一个时间戳。衰减项变成常数，**常数不能改变任何排序**，而且不会报错。

365 天单文件合成日记（12 个主题，决策在第 85/175/265 天被修订，24 道「X 现在设成什么」
的问句，半衰期 30 天）：

| 配置 | 首中 | 前三 |
|---|---|---|
| 只用相似度 | 8/24 | 17/24 |
| `0.75×相似 + 0.25×衰减`，时间戳 = **文件 mtime** | **8/24** | **17/24** |
| 同公式，时间戳 = **块级** | 14/24 | 14/24 |
| `相似 × (0.85 + 0.15×衰减)`，块级 | **20/24** | 23/24 |

第二行与第一行**逐题完全相同**：这个特性跑了、分配了内存、改变了零个排序。

诚实的边界：换英文日记复核时，乘性门只在「前三」领先、首中持平；而「mtime ≡ 不加时间」
那条在两种语言里都复现。

真实语料上的留出集（19 题，中文个人笔记）：**零依赖向量 14/19 首中、17/19 前三**；
换 bge-m3 嵌入为 17/19、18/19。同一批题、同一份语料，`decay-rag` 仓库里有可复跑的跑分器。

## 默认不进索引的目录

`archive/`、`rag/`、`*快照*`、`*定稿*`、`__pycache__` 等。理由：这些只是旧副本，会把真正的内容顶掉（实测某个关键词的第一命中会被工具自身的 README 抢走）。

`release/` 不在排除名单里——你自己的发布物（比如 decay-rag 的 README 和 docs）也是语料的一部分。
要调整就改 `SKIP_DIRS`，或用 `config.json` 的 `skip` 数组追加。

变更记录见 [CHANGELOG.md](CHANGELOG.md)。
